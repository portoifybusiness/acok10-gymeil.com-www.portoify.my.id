# Fitur Fitur utama portoify.my.id
Portoify dirancang sebagai platform SaaS manajemen karir dan berkas pelamaran kerja all-in-one yang modern dan terenkripsi. Fitur-fitur utamanya meliputi:
- Portofolio Digital Online (Subdomain Instan) Memungkinkan pengguna mempublikasikan profil diri, biodata, proyek unggulan, riwayat akademis, dan sertifikasi ke dalam tautan web publik yang responsif secara real-time: portoify.my.id/u/nama_kamu.
- Pembuat CV & Resume/CV Online
- Generator otomatis yang mempermudah pembuatan CV profesional terstandarisasi. Pengguna cukup mengisi formulir terpadu satu kali, lalu memilih template formal atau kreatif yang ramah HRD.
- Pembuat Surat Lamaran Kerja (Cover Letter Generator)
Generator pintar untuk merancang surat lamaran kerja kustom secara instan, menyatukan profil pengguna dan data lowongan tujuan dengan format yang rapi.
- Gudang Dokumen Terenkripsi ("Kelola Dokumen Anda")
Media penyimpanan aman untuk berkas krusial seperti KTP, NPWP, BPJS, Sertifikat Kompetensi, atau Surat Pengalaman Kerja. Seluruh dokumen disimpan dengan enkripsi biner lokal yang aman dari ancaman siber dan perayap luar.
- Pengelolaan Custom URL Domain (cPanel Hosting Integration)
Fitur premium yang memungkinkan pengguna mengatur nama folder deploy secara privat ke server public_html sehingga portofolio mereka terintegrasi dengan hosting cPanel personal.
- Paket Layanan SaaS Terintegrasi
Pilihan paket berlangganan mulai dari paket Basic, Standard, hingga Premium dengan gateway pembayaran terintegrasi untuk meningkatkan faksibilitas bandwidth, jumlah simpan dokumen, dan akses template profesional.
